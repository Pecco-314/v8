# TypeInjector 项目技术文档

> V8 TurboFan 编译器静态类型元数据注入系统

## 项目目标

在 V8 TurboFan 编译管线中注入静态类型元数据，通过确定性类型信息消除不必要的运行时类型检查，提升 JavaScript 执行性能。

## 技术架构

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────────┐
│  类型元数据源    │    │   类型描述语言    │    │   V8 TurboFan      │
│ (手写/未来扩展)  │───▶│      (TDL)       │───▶│   TypeInjector     │
└─────────────────┘    └──────────────────┘    └─────────────────────┘
                                │                         │
                                ▼                         ▼
                         ┌─────────────┐           ┌─────────────┐
                         │ TypeStorage │           │ 节点类型替换 │
                         │  元数据索引  │           │  检查消除   │
                         └─────────────┘           └─────────────┘
```

## V8 TurboFan 集成

### 编译管线位置

```cpp
// 在 src/compiler/pipeline.cc 中的集成
struct TypeInjectorPhase {
    DECL_PIPELINE_PHASE_CONSTANTS(TypeInjector)
    
    void Run(TFPipelineData* data, Zone* temp_zone) {
        TypeInjector injector(data->info(), data->graph(), 
                             data->common(), data->broker(), 
                             data->simplified());
        injector.Run();
    }
};

// 管线执行顺序
RUN_MAYBE_ABORT(TyperPhase, data->CreateTyper());
RUN_MAYBE_ABORT(TypeInjectorPhase);  // ← 新增阶段
RUN_MAYBE_ABORT(TypedLoweringPhase);
```

**位置选择原因**：
- **Typer 之后**: 已有基础类型推导信息
- **TypedLowering 之前**: 可影响后续节点降级
- **控制流确定**: 此时图结构已完整

### TypeStorage 全局单例

```cpp
class TypeStorage {
private:
    // 文件哈希 -> 字节码偏移 -> 类型签名
    std::map<std::string, std::map<int, std::vector<TypeAST>>> storage_;
    std::map<std::string, std::map<int, TypeAST>> return_types_;
    
    // 内建函数签名缓存
    std::map<int, BuiltinSignature> builtin_signatures_;
    
public:
    static TypeStorage* Get();  // 全局单例
    std::optional<std::vector<TypeAST>> GetParamTypes(std::string hash, int offset);
    std::optional<TypeAST> GetReturnType(std::string hash, int offset);
    std::optional<BuiltinSignature> GetBuiltinSignature(int builtin_id);
};
```

**索引策略**：
- **双重映射**: 文件哈希(SHA256) + 字节码偏移
- **惰性加载**: 按需读取元数据文件
- **内建函数缓存**: 避免重复解析

## 类型系统

### TypeAST 结构

```cpp
struct TypeAST {
    enum TypeKind : int {
        // 原始类型 (0-99)
        Any = 0, Void, Bool, Num, Str, Symbol, BigInt, RawInt32,
        // 复合类型 (100+)  
        Arr = 100, Tuple, Obj
    } kind;
    
    std::string field_name;        // 对象字段名
    std::vector<TypeAST> children; // 嵌套类型
};
```

### TDL 语法

**用户函数**：
```
[BytecodeOffset] @params [param1 param2 ...] @ret [return_type]

# 示例
369 @params any str @ret str
4749 @params any rawint32 rawint32 @ret rawint32
```

**内建函数**：
```
[BuiltinId] @params [receiver param1 ...] @ret [return_type]

# 示例  
1338 @params num @ret str  # NumberPrototypeToString
```

**复合类型**：
```
arr<T>, array<T>           # 数组
tuple<T1,T2,...>           # 元组
obj{f1:T1,f2:T2}          # 对象
```

## 优化实现

### 基础类型检查消除

```cpp
Reduction TypeInjector::ReduceCheckString(Node* node) {
    Node* input = node->InputAt(0);
    const TypeAST* input_type = GetNodeType(input);
    
    if (input_type && input_type->kind == TypeAST::Str) {
        // 类型确定，替换为 ChangeTaggedToTaggedPointer
        Node* replacement = graph()->NewNode(
            simplified()->ChangeTaggedToTaggedPointer(), input);
        SetNodeType(replacement, input_type);
        return Replace(replacement);
    }
    return NoChange();
}
```

### RawInt32 整数优化

**除法守护分支生成**：

```cpp
Reduction TypeInjector::ReduceCheckedInt32Div(Node* node) {
    Node* dividend = node->InputAt(0);
    Node* divisor = node->InputAt(1);
    
    if (!BothInputsAreRawInt32(dividend, divisor)) {
        return NoChange();
    }
    
    // 生成守护条件: divisor != 0 && !(dividend == INT_MIN && divisor == -1)
    Node* zero = jsgraph()->Int32Constant(0);
    Node* int_min = jsgraph()->Int32Constant(INT32_MIN);
    Node* minus_one = jsgraph()->Int32Constant(-1);
    
    Node* divisor_non_zero = /* divisor != 0 检查 */;
    Node* no_overflow = /* INT_MIN / -1 溢出检查 */;
    Node* safe_condition = /* 组合条件 */;
    
    // 构建分支：安全路径使用硬件除法，不安全路径回退
    Node* branch = graph()->NewNode(common()->Branch(), safe_condition, control);
    Node* if_safe = graph()->NewNode(common()->IfTrue(), branch);
    Node* if_unsafe = graph()->NewNode(common()->IfFalse(), branch);
    
    Node* safe_div = graph()->NewNode(machine()->Int32Div(), dividend, divisor, if_safe);
    Node* unsafe_result = GenerateFallback(dividend, divisor, if_unsafe);
    
    // 合并
    Node* merge = graph()->NewNode(common()->Merge(2), if_safe, if_unsafe);
    Node* phi = graph()->NewNode(common()->Phi(...), safe_div, unsafe_result, merge);
    
    return Replace(phi);
}
```

### 元组边界检查消除

```cpp
void TypeInjector::OptimizeTupleAccess(Node* bounds_check) {
    std::optional<int> const_index = TryGetConstantIndex(index);
    const TypeAST* array_type = GetNodeType(array);
    
    if (const_index && array_type && array_type->kind == TypeAST::Tuple) {
        int idx = *const_index;
        if (idx >= 0 && idx < tuple_size) {
            // 编译时确定索引安全，消除检查
            ReplaceWithValue(bounds_check, index);
            PropagateElementType(bounds_check, array_type->children[idx]);
        }
    }
}
```

### 可消除的节点类型

| 节点类型 | 消除条件 | 替换节点 |
|---------|---------|----------|
| CheckString | 类型为 Str | ChangeTaggedToTaggedPointer |
| CheckNumber | 类型为 Num | ChangeTaggedToTaggedPointer |
| CheckedInt32Add | 两操作数为 RawInt32 | Int32Add |
| CheckedInt32Div | 两操作数为 RawInt32 | Int32Div + 守护分支 |
| CheckedUint32Bounds | Tuple 常量索引 | 直接消除 |

## 工具链

### 核心脚本

1. **ts_to_metadata.js** (推荐):
   - TypeScript → Metadata 自动生成
   - 类型注解自动提取

2. **gen_metadata_info.py**: 
   - 解析 JavaScript 文件提取字节码偏移
   - 生成类型注解模板

3. **generate_graphs.py**:
   - 生成优化前后的 TurboFan IR 图
   - 地址规范化保证输出稳定

4. **generate_assembly.py**:
   - 生成优化前后的 x64 汇编代码
   - 对比最终机器码差异

5. **analyze_optimization.py**:
   - 统计节点变化
   - 生成优化分析报告

6. **verify_tests.py**:
   - 验证优化效果
   - 回归测试支持
