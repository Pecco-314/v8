# Metadata Type 架构重构概览

本文档描述重构后的 metadata 类型注入与优化流程，替代旧的 TypeInjector 单体实现。

## 目标

- 解耦：注入（写 Turbofan Type）与图改写（基于 metadata 的局部优化）分离。
- 明确阶段：不同优化在合适的 pipeline phase 执行。
- 可扩展：RawInt32 强度缩减预留独立 phase。

## 核心组件

### 1. Metadata 解析与存储
- 文件：`src/compiler/type-storage.cc` / `src/compiler/type-storage.h`
- 职责：读取 metadata 文件，解析为 `TypeAST`，按 `script_hash + start_pos` 存储。

### 2. MetadataTypeContext（跨 phase 共享）
- 文件：`src/compiler/metadata-type-context.cc` / `src/compiler/metadata-type-context.h`
- 职责：
  - 缓存当前函数的 `param_types_`
  - 保存 `Node* -> TypeAST*` 标签
  - 在函数切换时重置缓存
- 访问：`MetadataTypeContextStore::Get(graph)`

### 3. MetadataTypeHelper
- 文件：`src/compiler/metadata-type-helper.cc` / `src/compiler/metadata-type-helper.h`
- 职责：
  - `TypeAST` → Turbofan `Type` 映射
  - 读取/写入 `Node` 上的类型标签
  - 基于 `LoadField/LoadElement/Parameter` 递归推断 `TypeAST`

## Pipeline 阶段划分

### Phase A: MetadataTypeAnnotation
- 文件：`src/compiler/metadata-type-annotator.cc` / `.h`
- 位置：`Typer` 之后、`TypedLowering` 之前
- 作用：
  - 将 metadata 类型写入 Turbofan Type（仅注入，不改图）
  - 支持 `Parameter` / `LoadField` / `LoadElement` / `JSCall` 注入

### Phase B: MetadataBasedGraphOptimization
- 文件：`src/compiler/metadata-based-graph-optimizer.cc` / `.h`
- 位置：紧随 `MetadataTypeAnnotation`
- 作用：
  - 基于 metadata 标签进行图局部改写
  - 当前包含：
    - Tuple length 常量化
    - Tuple bounds 消除
    - **仅针对 Symbol 的 CheckMaps 消除**

### Phase C: RawInt32StrengthReduction（预留）
- 文件：`src/compiler/rawint32-strength-reduction.cc` / `.h`
- 位置：`SimplifiedLowering` 之后（可视 machine type）
- 说明：仅保留接口，未来实现强度缩减与溢出优化。

## 数据流示意

```
metadata 文件
  → TypeStorage
  → MetadataTypeContext (按函数缓存)
  → MetadataTypeAnnotation (写 Type)
  → MetadataBasedGraphOptimization (按标签改图)
  → TypedLowering / SimplifiedLowering
  → RawInt32StrengthReduction (预留)
```

## 调试与验证

- Graph 生成：`python3 scripts/generate_graphs.py`
- 验证：`python3 scripts/verify_tests.py`
- 观察阶段：`--trace-turbo-graph` 查看
  - `V8.TFMetadataTypeAnnotation`
  - `V8.TFMetadataBasedGraphOptimization`
  - `V8.TFRawInt32StrengthReduction`

## 备注

- RawInt32 当前未实现强度缩减，相关测试预期会失败。
- BigInt 消除依赖注入准确性，必须确保 `MetadataTypeContext` 在函数切换时刷新。
